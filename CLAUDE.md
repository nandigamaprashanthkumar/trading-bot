# Trading Bot

Forex scalping bot and analysis: the seven major pairs and XAUUSD on MetaTrader 5.

## Rules

- Keep replies short. Don't repeat earlier results or paste long output.
- Read only the parts of files you need. Run the smallest check that proves the change.
- Use `forex-market-analyzer` for prices and statistics; never quote them from memory.
- Test every strategy with spread and commission, on out-of-sample data.
- Use demo accounts only. Claude never places, changes or closes trades.
- This repo is public: never commit passwords, API keys, account numbers or trade history.
